# Katakolon Shore Excursions

Independent Katakolon cruise planning site for passengers calling at the Peloponnese port — gateway to Ancient Olympia.

**Domain:** https://katakolonshoreexcursions.com

## Development

```bash
npm install
npm run dev
```

## Build & QA

```bash
npm run build
npm run check-links
npm run seo-qa
```

## Deploy

Static export deployed via Cloudflare Pages:

```bash
npm run pages:deploy
```
